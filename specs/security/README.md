# SPECs de Segurança

Specs de requisitos de segurança que exigirem tratamento formal próprio
(ex.: autenticação/autorização, quando introduzidas). As diretrizes gerais
de segurança já vigentes desde a Fase 0 estão em `docs/security.md`. Vazio
até que uma necessidade concreta de segurança exija uma SPEC dedicada.
