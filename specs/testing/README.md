# SPECs de Testes

Specs de estratégias de teste que exigirem tratamento formal próprio (ex.:
testes de concorrência do laboratório de Race Condition). A estratégia
geral de testes está descrita em `docs/testing-guide.md` e nas seções de
"Estratégia de testes" de cada SPEC. Vazio até que uma necessidade
concreta exija uma SPEC dedicada.
